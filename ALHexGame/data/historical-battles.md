# Historical battle map notes

These five battlefields are playable regional interpretations for AL HEX NAVAL. Coastlines and distances are simplified for the hex board and are not intended for navigation or exact operational plotting. The location names and main geographic relationships follow the referenced U.S. Naval History and Heritage Command material. Fleet orders of battle and historical victory conditions are not implemented yet; battles currently use the existing player-versus-AI rules.

| Stage | Board | Geographic elements retained | Primary reference |

Terrain masks are stored as deterministic normalized polygons in `src/historical-battles.ts` and rasterized by `HexWorld`. This keeps the same five maps after reload and lets the existing fog, movement, minimap, and terrain renderer work without a second map engine. Campaign ports are named coastal objectives, not player headquarters, so a battle does not end immediately by controlling a single map objective.
