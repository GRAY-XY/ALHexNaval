# 碧蓝航线小人素材库

双击 `启动素材库.bat`，打开 `http://127.0.0.1:18766/`。保持启动窗口运行。已安装的 Python 3 用于本地文件服务，查看素材不需要 ADB、游戏、模拟器、原提取目录或网络。

## 浏览与播放

1. 左侧选择阵营，包括白鹰、皇家、重樱、铁血、META 和各联动阵营。
2. 点击角色，打开该角色的皮肤列表；可以按角色名、皮肤名、素材名称搜索。
3. 在皮肤列表中选择皮肤，右侧直接播放小人动画。动作菜单切换动作，支持暂停、播放速度、背景和缩放。
4. 所有动作都在当前素材库页面内播放，不需要下载文件。

“查看该皮肤的独立素材”打开此皮肤文件夹。素材按照 `assets/阵营/角色编号_角色名/skins/素材名称/` 存放。每个皮肤目录都带齐自己的 PNG 图集、atlas、skel 和 `__preview.png`，没有共享贴图引用、快捷方式或指向原目录的链接。可以单独复制整个皮肤目录作为后续素材。

## 内容和归类

收录 3259 项可见素材；原游戏的透明占位项 `none` 没有列入浏览界面。`素材索引.csv` 保存每项素材的阵营、角色、名称和独立路径。

角色和皮肤优先按 `ship_group` 编号归类，阵营取对应 `ship_data_statistics` 的 `nationality`。对相同 prefab 的 NPC / 玩家配置，优先选择存在舰船数据的角色编号。gift / takegift / chess 以及已知皮肤的额外变体归到相关角色，以“特殊动作 / 变体”标示。无法可靠匹配的素材按内部名称分组，阵营保留“未识别 / 其他”；它们包含敌人、小游戏角色和特殊效果，未猜测其阵营。

归类数据来自 [AzurLaneTools/AzurLaneLuaScripts](https://github.com/AzurLaneTools/AzurLaneLuaScripts)，对应 CN 的 `ship_skin_template`、`ship_data_statistics`、`name_code`、`nation` 和 `gametip`。数据快照保存在 `metadata/`；它们可能与本机游戏的个别配置存在差异。

本地播放器使用 PixiJS 7.4.3 / pixi-spine 4.0.6，运行文件已保存在 `vendor/`。旧提取目录和所有游戏实例均保留。

特殊贴图适配：`jianye_4` 的 PNG 从 512×512 调整到图集声明的 665×665，使通用 Spine 播放器正确解释坐标；原始导出图保留为 `jianye_4.original.png`。

`tools/build_library.py` 是本次整理素材时使用的打包脚本，重新打包时需要原提取目录；日常启动和播放不会调用它。
