# AL HEX NAVAL

AL HEX NAVAL is a browser-based prototype of a turn-based naval strategy game. Players command fleets across large hexagonal sea maps, explore through fog of war, fight with ships and aircraft, and capture ports. Matches support 2–8 factions controlled by local players or AI.

The project uses Azur Lane chibi characters and combat assets. This repository contains the TypeScript/PixiJS game in `ALHexGame/` and a standalone asset library in `ALChibiAssets/`. Online multiplayer is planned for a later stage.
